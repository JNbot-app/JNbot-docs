# First steps

Start with the server profile you want to use. Then add an account and try one of the ready-made scripts or a recorded task.

## Choose a server profile

On first launch, choose a server from the profile list and select **Add server** to make it active.

If your server is not listed, select **Create profile**. Enter a name, server address, and at least one gamemode, then save. You can change the active profile later from **Server profiles**. The [profile guide](../profiles/overview.md) explains what the other settings do.

## Add an account

Open **Accounts**, select **Add Alt**, and enter the Minecraft username. Choose **Premium** for a Microsoft account. For a cracked account, leave the switch off. Add the server password only if the server asks you to use `/login`.

Follow the [step-by-step alt guide](./alts.md) to save ranks, organize accounts with tags, or import a list.

## Run a ready-made script

Open **Dashboard**, find a script, and select **Run**. If it needs an account, add one first. Some scripts also ask you to choose an account or change settings before they start.

## Record a task to replay later

Open **Plugins** and select **Create**. Choose **Recording** under **Language** to capture actions in Minecraft without writing code. The [record and replay guide](../plugins/recordings.md) walks through the process.

## Building plugins

If you are writing code, start with the [plugin development overview](../plugins/overview.md). It links to the [Bot API](../plugins/code-based/bot.md) and [Script API](../plugins/code-based/script.md). The top menu also has the full [developer guide](../plugins).
