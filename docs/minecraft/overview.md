# Minecraft servers

Use **MC Server** in the desktop app to host a private world or join one shared
by someone else. JNbot handles the private connection, so you do not need to
set up router port forwarding.

## Create a managed server

1. Open **MC Server** and select **New managed server**.
2. Choose a name, a supported Minecraft version and the amount of memory.
3. Optionally select an existing world, then accept the Minecraft EULA.
4. Create the server and select **Start** when it is ready.
5. Select **Copy invite** and send the invite code to your friends.

The server runs on your computer. Keep JNbot open while friends are playing.
Only one local world can be hosted at a time.

## Share a world already open in Minecraft

Select **Share your world**. For the simplest setup, launch Minecraft with
JNbot Client, open a world, select the connected client, and start sharing.

You can also share a world opened to LAN by choosing **LAN port** and entering
its Minecraft version and LAN port. Copy the invite once sharing starts.

## Join a private server

Choose **Join with invite**, paste the invite code from the host, and select
**Add server**. It appears under **Joined**. The host must keep their world
running for you to connect.

## Keep invites private

Anyone with an invite can request access to that private world. If an invite
was shared accidentally, open the server menu and select **Rotate invite
code**.
