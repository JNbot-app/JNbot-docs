# Server profiles

A server profile stores the connection details and settings JNbot uses for one Minecraft server. The active profile controls which server appears in the app and which alts, scripts, ranks, and gkits belong together.

JNbot includes ready-made profiles for supported servers. You can use one as it is, or make a copy if you want to change its settings. You can also create a profile for a server that is not listed.

## Use a ready-made profile

Open **Server profiles** and select the profile you want. Its row shows **ACTIVE** when JNbot is using it. Your dashboard and account list follow the active profile.

## Make your own profile

Select **Create profile** to open the profile wizard. You need a name, server address, and at least one gamemode. The remaining steps are optional for basic use. You can leave ranks, gkits, dashboard shortcuts, and custom display settings for later.

To change a ready-made profile, choose **Clone to edit** first. JNbot keeps the original and creates a separate copy for your changes.

## What a profile contains

- **Identity** includes the profile name, short name, icon, and brand color.
- **Connectivity** includes the server address, port, and optional alternate addresses.
- **Gamemodes** lists the server lobbies and how a bot joins each one.
- **Ranks & GKits** stores rank prices and gkit cooldowns for account details and related tools.
- **Scripts** chooses which scripts appear as dashboard shortcuts for this server.
- **Profile UI** selects the optional player details panel.
- **Bot extension** selects an optional plugin loaded for each bot on this server.

See [the profile wizard](./wizard.md) for a plain-language explanation of each step, or [managing profiles](./managing.md) to switch, edit, import, or export a profile.
